# FixMate – On-Demand Service Booking App

A web application where customers can book home service professionals like plumbers, electricians, mechanics and more.

---

## How to Run

### Requirements
- Node.js 18 or higher
- npm 8 or higher

### Steps

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open your browser and go to:
# Local:   http://localhost:5173

To access from your phone (on same WiFi):
# Network: http://YOUR_IP:5173

## What This App Does

**As a Customer:**
- Browse home services like plumbing, electrical work, cleaning etc
- Search and filter by service type
- View worker profiles with ratings and experience
- Book a worker with date, time and address
- Choose to pay by cash or card
- Track your bookings
- Get notifications when worker accepts or rejects

**As a Worker:**
- Set yourself as available or unavailable
- See incoming job requests
- Accept or reject bookings
- Mark jobs as complete
- Track earnings
